설치기와 구조 검사기는 같은 원본 완전성 함수를 사용합니다. 본문, 다섯 참조와 그 문서들의 로컬 연결, agents/openai.yaml, 스킬 내부 NOTICE, 필요한 저작권 고지를 확인합니다. 현재 패키지의 인라인 Markdown 링크 형식에 대한 검사이며 임의의 Markdown 확장 문법을 모두 해석하는 도구는 아닙니다.

- **불완전한 원본:** 필요한 참조·본문·메타데이터·고지를 각각 없앤 사본은 미리 보기·설치·확인에서 종료 코드 2로 중단됐습니다. 설치 대상이 없으면 새 파일·폴더를 만들지 않았고, 이미 설치한 대상도 그대로였습니다. 참조 문서 안의 누락 링크와 스킬 밖을 가리키는 로컬 링크도 거부했습니다.
- **중첩 복사:** 원본 자체와 원본 하위 폴더를 대상으로 지정한 경우, 복사 결과가 원본을 포함하는 경우 모두 변경 전에 중단됐습니다.
- **기존 동작:** 정상 설치·재설치·충돌 중단·기존 지침과 데이터 보존·미리 보기 무변경·반복 설치의 내용과 수정 시각 보존을 확인했습니다.
- **직접 읽기:** 등록하지 않은 원본에서도 본문과 참조가 유효함을 확인했습니다. 이 파일 검사는 호스트의 발견·선택·지침 준수 검증과 다릅니다.

제외한 1개는 **심볼릭 링크 대상 거부 검사**입니다. 이 Windows 환경에서 테스트용 링크 생성이 허용되지 않아 실행하지 못했습니다. 링크 경로를 거부하는 코드는 유지했지만 실제 해당 검사가 통과했다고 표시하지 않습니다.

키트 루트에서 재현할 명령은 다음과 같습니다. 현재 환경에서 사용 가능한 Python 명령을 사용합니다.

```text
python checks/check_package.py
python -m unittest discover -s tests -v
```

필요하면 SKILL_TEST_TMPDIR 환경 변수로 테스트용 임시 폴더를 지정합니다. 외부 패키지나 서비스를 새로 설치하지 않았습니다.

## 이번 대화 흐름에서 관측한 것

독립 실행 에이전트에 최종 SKILL.md와 필요한 내부 참조, 이미 있던 자체 연습 프로젝트만 제공했습니다. 다섯 요청을 순서대로 보냈으며 기대 답이나 의심 원인은 제공하지 않았습니다.

1. 설명 요청에서는 실제 자료의 예로 용어와 파일 역할을 설명했습니다. 실행 전후 파일 내용과 수정 시각이 같았습니다.
2. 실행을 승인한 뒤 기존 프로그램을 실제 실행했습니다. 결과는 주문수 4, 주문금액 4000, 환불액 800, 순매출 3200, 평균 순매출 800이었습니다.
3. 결과를 확인할 실제 파일과 볼 행·열·단위를 안내했습니다.
4. 사용자가 아직 파일을 열지 않았다고 해도 다음으로 요청한 중복 환불 확인을 진행했습니다.
5. 최종 안내만 다듬고 수치·원본·프로그램·파일 구조를 유지했습니다. 새 기능이나 보고서를 만들지 않았습니다.

주 실행자가 원본·코드·결과의 내용과 파일 구성을 다시 대조했습니다. 이 확인은 **지침을 명시적으로 읽힌 작은 흐름 1회**입니다. Cofa, 네이티브 자동 선택, 여러 모델의 성능 비교나 큰 과제 전반의 품질을 검증한 결과는 아닙니다.
