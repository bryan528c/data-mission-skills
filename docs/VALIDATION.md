# 검증 결과와 남은 확인

검증일: 2026-10-31 (한국 시간). 로컬 Windows 환경에서 수행했습니다. **지침·설치기·연습 결과를 확인했으며, Cofa에서 직접 인식시켜 실행한 검사는 아닙니다.**

## 확인 결과

| 검사 | 실제 결과 | 의미와 한계 |
| --- | --- | --- |
| Codex 공식 quick_validate | 통과 | 스킬 frontmatter·이름·기본 형식 확인. 행동 품질이나 자동 선택의 증명은 아님. |
| 배포 파일·UTF-8·참조 링크·메타데이터 | 통과 | 공개할 파일만 지정하고, 5개 참조와 라이선스가 함께 전달되는 구조 확인. |
| 병행 개정본의 구조 검사기 | 통과 | 한 진입점·다섯 참조·메타데이터·저작권·시나리오 상태 확인. |
| 오프라인 설치기 자동 검사 | 9개 중 8개 통과, 1개 제외 | 미리 보기, 전체 복사, 반복 설치, 충돌 시 중단, 기존 자료 보존, 잘못된 대상과 설치 확인 검사. |
| 설명 전용 독립 실행 | 확인 | 기본 뜻과 가상 예, 실제 규칙 우선, 열린 파일과 작업 범위, Skill/MCP의 역할을 설명. 실행·설치로 확대하지 않음. |
| 데이터 수정 독립 실행 | 확인 | 실제 프로그램 실행과 CSV 생성. 주문수 4, 주문금액 4000, 환불액 800, 순매출 3200, 평균 800. |
| 마감 안내 후속 요청 | 확인 | 기존 수치·구조를 유지하며 열 파일·볼 항목·단위를 안내. 새 기능·별도 보고서 없음. |
| 원자료와 최종 수치 재확인 | 확인 | 주 실행자가 제공했던 원본 CSV·NOTES 내용 및 결과를 다시 비교하고 프로그램을 재실행. |

설치기 검사는 `python -m unittest discover -s tests -v`로 실행할 수 있습니다. 별도 임시 폴더가 필요하면 `SKILL_TEST_TMPDIR` 환경 변수로 검사 공간을 지정할 수 있습니다.

제외한 1개는 **심볼릭 링크 대상 거부 검사**입니다. 실행한 Windows 환경에서 해당 링크를 만들 수 없어 테스트를 수행하지 못했습니다. 코드에 링크·Windows 연결 경로 확인이 있지만 이 검사까지 통과했다고 표시하지 않습니다. 네트워크·전역 설정을 바꾸는 설치 기능은 없습니다.

## 동작을 어떻게 확인했나

두 독립 검토에 각각 설명 요청과 잘못된 계산이 있는 연습 프로젝트를 제공했습니다. 스킬을 명시적으로 읽게 했고, 기대 답이나 의심 원인을 제공하지 않았습니다. 주 실행자는 생성 파일·수치·보존 범위와 답변을 확인했습니다. 데이터 사례 뒤에는 마지막 안내만 다듬는 요청을 추가했습니다.

연습 자료와 평가 범위는 [사례 문서](eval-cases.md)에 있습니다. 이전 버전과의 대조 실험, 많은 과제에서 반복한 통계 평가, 다른 모델과의 비교는 하지 않았습니다. 따라서 속도·점수 향상을 수치로 주장하지 않습니다.

## 보존한 검토 시나리오

병행 개정본의 [22개 행동 시나리오](../checks/scenarios.json)는 기대 행동을 설계한 자료로 보존했습니다. 이 22개를 모델로 실행한 통과 기록으로 세지 않습니다. 해당 개정의 과거 검증 기록은 [고정 커밋의 기록](https://github.com/bryan528c/data-mission-skills/blob/f2d005e6dbbe651f541044c5f3a5e7272d8e49b6/docs/VALIDATION.md)에 남아 있으며, 현재 Windows 검사·독립 실행 결과는 위 표를 따릅니다.

통합 후 참조 경로·라이선스·추가 지침을 다시 검사하고 설치 테스트를 재실행했습니다. 독립 실행 두 사례는 통합 직전 지침으로 진행한 결과입니다. 마지막 통합본 전체에 새 독립 모델 실행을 했다고 주장하지 않습니다.

## 대상 환경에서 남은 확인

- **Cofa의 스킬 자동 발견과 자연어 선택:** `allow_implicit_invocation: true`는 허용 설정입니다. 해당 호스트에서 실제 목록에 보이고 적절한 요청에 선택되는지 별도로 확인해야 합니다.
- **Linux와 Cofa 파일 권한:** 설치기는 Python 표준 라이브러리만 사용하지만 해당 환경에서 직접 실행한 호환성 검사는 아직 하지 않았습니다.
- **MCP 연결:** 이 패키지는 특정 MCP를 요구하거나 설정을 변경하지 않습니다. 실제로 필요한 연결의 설정·권한·호출 성공은 별도 작업입니다.
- **원본 화면 기반 조작 안내:** 이 스킬 개정은 Cofa UI의 위치·버튼·모델 메뉴를 검증하는 시각 자료가 아닙니다. 확인하지 않은 화면을 생성하지 않습니다.
- **넓은 과제 범위:** 빈 대상, 상충하는 이벤트, 복잡한 날짜·통화, 대형 자료 등은 이번 작은 연습의 검증 범위에 포함되지 않습니다. 실제 과제에서 필요한 사례를 추가 확인해야 합니다.

자동 발견이 지원되지 않으면 [시작 안내](../START_HERE.md)를 직접 읽혀 현재 대화에 적용할 수 있습니다. 이 우회 방식도 호스트 자체의 자동 선택 검증으로 표현하지 않습니다.
