# 확인한 범위와 남은 검증 · v2

2026-10-31. **파일 구조를 검사한 것과 모델이 잘 쓰는 것을 검증한 것은 다릅니다.**

## 실제 실행한 확인

`python checks/check_package.py`를 이 제작 환경에서 실행했고 구조 검사가 통과했습니다. 별도 임시 폴더를 사용한 다음 총 12개 확인도 예상 결과와 일치했습니다.

- 정상 패키지, 한글·공백 경로 복사본, Git 메타데이터가 있는 폴더: 정상 통과.
- 오류 해결 참조 파일을 제거한 사본: 참조 누락으로 실패.
- 자동 선택 정책을 false로 바꾼 사본: 설정 검사 실패.
- 외부 저작권 파일을 제거한 사본: 고지 누락으로 실패.
- 이전 Chat판의 저작권·상위 고지 4개: 바이트 동일.
- Work판 원래 LICENSE와 .gitignore: 원래 Git blob SHA와 동일.

검사기는 한 개의 진입 스킬, 다섯 참조의 경로 연결, 메타데이터 형식·이름·짧은 설명 길이, 명시된 자동 선택 정책, 포함 파일 유형, 일부 알려진 개인 식별 문자열 등을 확인합니다. 완전한 보안 감사나 모든 비밀정보 탐지기가 아닙니다. 개발 중 검사기가 자기 캐시 파일까지 배포 파일로 판단한 문제를 수정하고, Git 메타데이터를 포함한 경우도 재확인했습니다.

## 내용 검토

기존의 원본 보존·근거 계산·이전 장점 유지·제한시간·권한 경계를 유지하고, 다음 누락을 보완했습니다.

- 기본 뜻·이유·구체 사례·파일 확인 위치 연결.
- 계획만 요청한 경우와 실행을 승인한 경우 구분.
- 보고와 다음 단계 승인을 구별하고, 사용자가 요청한 단계별 확인은 보존.
- 관련 보조 지침을 AI가 골라 읽는 조건 명시.
- 오류 반복 중단, 실질적인 도구 선택, 실제 증거 중심 확인.
- 마지막 정확성·내용 연결·표현·가독성 정리를 한 번 수행하고 종료.

22개 상황을 `checks/scenarios.json`에 정의했습니다. 여기에는 단순 개념 질문, 계획만 요청, 승인 후 자율 진행, 사용자가 요청한 중간 확인, 모호한 업무 기준, 파일·폴더 질문, 반복 오류, 도구 필요/불필요, 기존 장점 보존, 7분 마감, 기본 설명 누락, 테스트0개, 실제 화면 미확인, 세션 재개, 외부 지시, AI 금지 단계, 무관한 번역, 최종 종료, 로컬 Git 기록이 있습니다.

**이 22개는 기대 행동을 정한 검토 시나리오이지 실제 모델 22회 실행의 통과 결과가 아닙니다.** 설명 예시 역시 실제 시험 자료가 아닌 이해를 위한 사례입니다.

## 아직 확인하지 못한 것

- 실제 Cofa에서의 Skill 발견·암시적 호출·참조 선택·지침 준수.
- 사용자의 Codex 모델에서 v1/Work판 대비 품질·시간·토큰 향상.
- 실제 MCP 연결, Windows에서의 실행, 대회 평가 결과.

이 제작 환경에 실행 가능한 Codex CLI가 없어 모델 비교 실험은 수행하지 않았습니다. 해당 한계를 파일 검사 성공으로 대체하지 않습니다. 자동 호출을 허용하는 설정은 항상 호출된다는 보장이 아닙니다.

실사용 점검은 시험 전 개인 연습에서 “설명만 요청 → 승인한 작은 결과 실행 → 오류 하나 수정 → 결과 파일 확인 → 최종 정리”를 한 번 이어가며 보면 됩니다. 실패한 실제 장면이 있으면 그 장면에 필요한 지침만 수정하고 전체 묶음을 다시 키우지 않습니다.
