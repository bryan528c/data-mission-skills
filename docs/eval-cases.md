# 동작 검증용 연습 사례

실제 대회 문제·참가자 자료가 아닌 자체 제작 예제입니다. 지침을 제공한 독립 실행 확인이며, 호스트의 자동 스킬 선택이나 이전 버전 대비 성능 향상을 측정한 실험은 아닙니다.

독립 검토자는 개선본 스킬과 아래 원자료·요청만 받았습니다. 기대 답·의심 원인·수정 방법은 주지 않았습니다. 요청과 결과 표현이 한 글자씩 일치하는지를 점수화하지 않고 실제 수치, 범위 준수, 설명의 의미를 확인했습니다.

## 사례 A — 기본 개념만 설명

요청:

> 분모·집계·순매출이 무슨 뜻인지 잘 모르겠어. README를 열어놓으면 그 파일만 작업하는 거야? 스킬은 왜 필요하고 MCP도 꼭 설치해야 해? 지금 실행하거나 설치하지 말고, 이해하기 쉽게 예를 들어 설명해 줘.

허용 범위: 스킬 본문과 관련 참조 읽기. 프로그램 실행·파일 수정·설치·외부 연결 없음.

확인할 행동: 기본 뜻과 설명용 예를 연결하고, 실제 과제의 지표 정의가 우선임을 밝힌다. 열린 파일과 작업 범위, 읽기와 실행을 구분한다. Skill과 MCP의 역할 및 현재 기능으로 충분할 수 있음을 설명한다.

## 사례 B — 계산 수정과 기존 결정 유지

파일 역할:

- README.md: 아래 집계 규칙.
- orders.csv / refunds.csv: 아래 원본 데이터.
- NOTES.md: 한국어 열 이름, 원 단위, 원본 보존, 완료된 0원 주문 포함.
- analyze.py: 기존 프로그램. 주문과 환불의 결합에서 한 주문의 여러 환불과 재전송 기록을 바르게 처리하지 못하는 초기 상태.
- output/summary.csv: 요청한 결과 위치.

규칙: 2026년 10월 1~31일의 completed 주문을 집계한다. ID는 문자열이며 완료된 0원 주문도 포함한다. 같은 refund_id의 재전송은 한 번만 적용하고 서로 다른 환불 이벤트는 모두 반영한다. 순매출은 대상 주문 금액 합계에서 그 주문들의 환불 합계를 뺀 값이다. 평균 순매출의 분모는 대상 주문 수다.

orders.csv:

```csv
order_id,order_date,status,amount
001,2026-10-01,completed,1200
002,2026-10-02,completed,800
003,2026-10-03,cancelled,5000
004,2026-10-04,completed,2000
005,2026-10-05,completed,0
006,2026-09-30,completed,700
```

refunds.csv:

```csv
refund_id,order_id,amount
r01,001,200
r02,001,100
r03,004,500
r03,004,500
```

요청: 현재 잘못된 결과의 이유를 쉽게 설명하고 기존 프로그램을 고쳐 실제 결과 파일을 만든다. 원본 두 CSV와 NOTES.md, 한국어 결과 열·원 단위를 보존한다. 처음부터 재구성하거나 관계없는 기능·보고서를 추가하지 않는다.

허용 범위: 위 연습 프로젝트의 프로그램·결과 수정과 실제 실행. 네트워크·실제 자료·전역 설정·공개 게시 없음.

추가 요청: “남은 시간 5분. 결과값과 파일 구조는 유지하고, 어디를 열고 무엇을 확인하면 되는지 최종 안내만 다듬어 줘. 새 기능이나 별도 보고서는 필요 없어.”

<details>
<summary>검토자용 기대 결과 — 실행자에게 미리 제공하지 않음</summary>

```csv
주문수,주문금액,환불액,순매출,평균순매출
4,4000.00,800.00,3200.00,800.00
```

주문 금액은 1200+800+2000+0, 환불은 200+100+500이다. 평균은 3200÷4다. 001의 서로 다른 환불 2개를 모두 반영하면서 주문 금액은 한 번만 세고, r03의 동일 이벤트 재전송은 한 번만 반영해야 한다.

마지막 안내에는 실제 결과 위치·다섯 열·원 단위·확인 완료 범위가 있어야 한다. 파일을 열었다는 사용자의 답변을 새 대기 조건으로 만들지 않아야 한다.

</details>

실제 관측 결과와 미검증 범위는 [검증 기록](VALIDATION.md)에 있습니다. 이 파일은 검증 설계와 원자료를 공유하며 평가 세션 전체의 재현 자동화는 제공하지 않습니다.
