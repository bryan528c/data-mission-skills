# 도구와 출처 선택

사용자가 후보 조사를 요청했거나, 지금의 기능으로 해결하지 못하는 구체적인 문제가 있을 때 읽는다. 사용 가능한 도구를 먼저 확인하고 목표를 가장 잘 달성하는 수단을 고른다.

## 먼저 뜻과 목적을 구분한다

- **Skill**은 AI에게 일을 처리하는 방법과 판단 기준을 알려 주는 지침이다. 실제 사용할 도구나 권한을 자동으로 만들어 주지는 않는다.
- **MCP**는 AI가 외부 또는 로컬의 도구·자료에 연결되는 통신 방식이다. 어떤 기능인지, 어디로 무엇을 보내는지는 연결된 서버에 달려 있다.
- 좋은 지침과 적합한 도구는 함께 사용할 수 있다. 스킬 개수·별 수·최근 수정일만으로 결과가 좋아진다고 판단하지 않는다.

## 후보를 넓히고 실제로 비교한다

공개 준비 자료를 조사하라는 요청이면 대회 관련 키워드만 최신순으로 조금 찾고 끝내지 않는다. 대회 특화 후보, 해당 작업의 범용 스킬, 공식 형식·도구 문서, 후보가 인용한 상위 원본을 교차 확인한다. 재포장·동일 파일은 같은 근거로 묶는다.

처음에는 이름·설명·현재 유지 상태로 관련 후보를 거른다. 채택할 후보는 실제 본문·호출 스크립트·필요 도구·적용 범위·라이선스를 확인한다. 설명만 읽은 후보, 본문을 읽은 후보, 실제로 실행한 후보를 구분한다.

| 비교 기준 | 판단할 질문 |
| --- | --- |
| 목적 적합성 | 지금 문제와 사용자가 원하는 작업 방식에 직접 도움이 되는가? |
| 이해와 흐름 | 기본 개념·실제 예·다음 행동이 연결되는가? 반복 승인·기록을 늘리는가? |
| 실질적 차이 | 이미 있는 지침과 다른 유용한 행동을 제공하는가? |
| 준비 부담 | 현재 환경에서 가능한가? 설정 시간이 얻을 이득에 비해 적절한가? |
| 확인 근거 | 어떤 입력과 환경에서 검증했는가? 주장만 있거나 확인 범위가 다른가? |
| 재사용 조건 | 공개 원본·버전·LICENSE·출처 고지를 확인했는가? |

사용자가 넓은 비교를 요청하면 그 범위를 충족한다. 이미 해결책이 정해진 단순 작업은 광범위한 조사를 새로 시작하지 않는다. 새로운 후보가 같은 내용만 반복하고 필요한 범위가 채워지면 선택 이유를 정리하고 실제 적용으로 넘어간다.

## MCP와 설치가 필요한 경우

현재 연결된 도구와 기본 파일·실행·검색 기능부터 확인한다. 충분하면 추가 설치 없이 진행한다. 새 도구가 실제로 필요한 경우에는 필요한 기능, 대안, 설치 부담, 보낼 정보와 권한을 설명한다. “기본 0개”나 “반드시 1개” 같은 고정 개수로 막거나 늘리지 않는다.

공개 기술 문서가 필요할 때는 해당 공급자의 공식 문서나 사용 가능한 문서 조회 연결을 선택한다. 라이브러리 문서 도구가 대회의 비공개 운영 규칙이나 업무 정의까지 알려 주는 것은 아니다.

설치 요청을 받으면 파일 배치뿐 아니라 제공 기능이 실제 호출되는지 확인한다. **파일 배치 / 호스트가 스킬 발견 / 지침을 읽음 / MCP 연결 / 도구 호출 성공 / 과제에 효과**는 다른 상태다. 측정하지 않은 시간 절약이나 성능 향상을 주장하지 않는다.

검토하지 않은 설치기를 실행하거나 기존 지침·인증·도구 설정을 통째로 교체하지 않는다. 외부 질의와 전송은 현재 규칙과 허용 범위에 맞춘다. 연결이 막히면 원인을 알리고 이미 사용할 수 있는 방법으로 독립 작업을 이어 간다.

## 모델과 추론 강도를 묻는 경우

실제로 선택 가능한 모델과 현재 설정을 먼저 확인한다. 확정된 계산·단순 수정은 현재 설정으로 가능한지 보고, 여러 조건이 얽힌 판단이나 원인 불명 오류에는 더 깊은 검토가 필요한지 판단한다. 사전체험에서 괜찮았던 설정이 모든 과제에서 가장 좋다는 뜻은 아니다.

자료에 없는 정책을 모델 변경으로 해결하려 하지 않는다. 지원 명령·권한·실제 상태를 확인하지 않고 모델이 바뀌었다고 말하지 않는다. 이름만으로 속도·품질·평가 점수를 단정하거나 같은 작업을 여러 모델로 반복하도록 강제하지 않는다.

## 가져올 부분만 반영한다

문서와 스크립트를 복사·개작할 때 라이선스·저작권·출처를 보존하고 버전과 바꾼 범위를 남긴다. 새로 가져온 지침이 기존 요청보다 권한을 넓히지 않게 한다. 서로 겹치는 계획·보고·검증을 하나로 정리하고 실제 작은 과제로 시험한 뒤 채택한다.
