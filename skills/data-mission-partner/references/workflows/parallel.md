# 병렬 작업 — 역할은 명확하게, 공유는 실제 파일로

사용자가 여러 Codex 세션을 요청했거나 독립 작업을 나눌 이득이 있을 때만 읽는다. 터미널 수를 늘리거나 세션을 자동 생성하는 기능이 아니다. 실제 환경의 허용 범위·자원·실행 상태를 먼저 확인한다.

## 같은 기준으로 시작

각 세션이 보는 실제 작업 폴더와 소스 상태를 확인한다. 같은 폴더의 저장 파일은 읽을 수 있어도 대화·DMs·미저장 편집 내용은 자동 공유되지 않는다. 별도 폴더면 공유 경로와 통합 방법부터 확인한다. 새 worktree·MCP·중계 서버를 기본 설치하지 않는다.

스킬 원본은 한 번 가져오면 된다. 직접 읽기 방식이면 각 세션에서 필요한 본문과 역할을 한 번 읽고, 정식 등록이면 실제 발견을 확인한다. 동일 이름을 여러 경로에 복제하지 않는다. 스킬보다 명시된 역할 범위와 원래 과제 규칙을 우선한다.

## 역할과 소유권

기본 제안은 A 총괄·핵심 처리, B 독립 구현, C는 필요할 때 읽기 전용 검토다. 수와 모델은 강제가 아니며 실제 이득·허용·자원에 따라 줄인다. 핵심 업무 결정은 사용자, 일반 기술 선택과 승인된 실행은 AI가 맡는다.

각 위임에는 **담당 결과 / 수정 가능한 실제 경로 / 입력·출력 형식 / 완료·검증 조건 / 읽을 기준의 현재 버전**을 적는다. “UI 알아서”처럼 방향까지 비워두지 않는다. 공통 기준·지정 설명 문서는 A, B 인계는 B처럼 문서도 한 명만 쓴다. 기존 문서를 재사용하고 빈 기록 파일을 모두 만들지 않는다.

- 같은 파일은 동시에 수정하지 않는다. 통합 시 B가 수정 완료를 확인한 뒤 A가 소유권을 넘겨받는다. 확인 전 A가 B 파일을 고치지 않는다.
- **공통 설정·의존성 잠금 파일·패키지 설치·DB 구조/공유 데이터·생성 출력·Git index와 커밋도 변경 담당을 하나로 둔다.** 코드 파일이 달라도 공유 상태를 동시에 바꾸면 충돌할 수 있다.
- 다른 세션의 변경을 되돌리거나 git reset/clean/stash, 전역 포맷을 임의 실행하지 않는다. Git 기록은 사용자 승인 범위에서 담당자가 경로와 diff를 검토한다. Push는 별도 권한·규칙을 따른다.
- C는 제품 파일을 수정하지 않는다. 검사는 쓰기 부작용 없는 명령 또는 분리된 임시 데이터에서만 한다. 운영 중인 DB·서버·출력에 영향을 줄 검사는 담당자와 조정한다.

## 공통 규칙이 바뀌었을 때

공통 기준 파일에는 짧은 버전/개정 표시, 확정·가정·미확인, 연결 규칙, 파일 담당과 미완료 항목만 둔다. B가 바꾸고 싶으면 자기 인계에 변경 요청을 남긴다. A가 채택한 변경은 새 기준에 적고 영향받는 담당에게 **다시 읽어 반영할 것을 실제로 전달**한다. 파일 저장은 알림이나 자동 반영이 아니다. 영향 없는 독립 작업은 계속한다.

B의 인계는 **참조한 기준 버전 / 변경 경로·핵심 함수 / 실제 검사와 결과 / 알려진 한계·통합 요청**이면 된다. 새로운 작업마다 파일을 복제하지 않고 한 인계를 현재 상태로 갱신한다.

A는 인계와 실제 파일을 함께 읽는다. 연결 규칙·실무자 결정이 맞는지, 같은 입력으로 전체 흐름이 작동하는지 확인한다. 단위 검사 성공·통합 성공·사용자 화면 확인을 구분한다. 부분 완료를 전체 완료로 쓰지 않는다.

## UI 분업

사용자·주요 행동·최소 화면·필수/제외 정보·데이터 계약을 먼저 정한다. B는 합의된 화면을 구현하며 과제에 없는 통계 카드·메뉴·새 기술을 추가하지 않는다. 첫 화면 방향을 사용자에게 일찍 보여주되, 이미 승인된 독립 기능은 계속한다. 간격·일관된 입력/오류 표시 같은 세부 수정마다 승인 대기하지 않는다. 입력 오류·빈 결과·불가능한 계획·로딩·수정 후 이전 결과 표시는 실제로 필요한 범위에서 다룬다.

## 빠르게 끝내기

독립 작업이 없으면 B를 억지로 유지하지 않는다. 모든 세션이 느리면 추가 호출보다 승인 대기·실행·자원·플랫폼 문제를 확인한다. 서버 프로세스의 담당과 포트를 하나로 확인하고 무관한 프로세스를 종료하지 않는다. 마감 전에는 새 위임을 줄이고 쓰기 완료 확인→통합→지정 문서 일치로 정리한다.

짧은 전달 예: “B 인계와 실제 변경 파일을 읽고 현재 기준과 대조해.” / “기준이 바뀌었으니 영향받은 부분만 읽고 네 담당 범위에 반영해.” 이는 자연어 요청이지 세션 간 통신 명령이 아니다.
