# 실제 구현과 지정 설명을 연결하기

제출 설명 양식이 있거나 사용자가 설계 이해·서술형 사전 대비를 요청했을 때 읽는다. 일반 답변마다 문서나 퀴즈를 만들지 않는다. AI 사용이 허용된 작업 단계에서만 적용한다.

## 양식을 먼저 확인한다

실제 과제의 양식 파일·필수 항목·파일명·위치·허용 분량·기계가 읽는 필드명을 확인한다. **양식 우선**이며 임의의 STRUCTURE_MAP이나 보고서로 대체하지 않는다. 없는 양식을 공식 양식처럼 지어내지 않는다. 원본 내용을 보존하고 수정할 문서인지 읽기 전용 템플릿인지 지시서를 따른다.

공식 항목을 내부 근거와 연결하되 스키마를 임의로 늘리지 않는다. 필요하면 허용된 짧은 작업 메모를 보조로 쓰고, 별도 메모가 제출 제외라고 가정하지 않는다. 지정 양식이 없으면 요구된 산출물만 만든다.

## 중요한 기능마다 근거를 연결한다

**요구/질문 → 확인한 답 또는 사용자 판단 → 실제 파일·함수 → 처리와 결과 → 검증 → 한계**를 연결한다. 양식 안에 맞게 표현하고 아래 표를 새로운 제출 규격으로 강제하지 않는다.

| 연결할 사실 | 확인 방식 |
| --- | --- |
| 담당자에게 물은 내용·답변 | 실제 전달받은 내용과 조건을 확인. 직접 보지 못한 DM은 봤다고 하지 않음 |
| 사용자가 결정한 기준 | 명시한 선택과 이유. AI가 제안만 한 것은 별도 |
| 코드 위치 | 실제 정의와 사용 지점을 읽어 함수 역할 확인. 파일명 추측 금지 |
| 입력·변경·저장·조회 | 한 입력이 어디를 거쳐 결과가 되는지 따라감 |
| 검증 | 실제 입력·기대값·실제값·사용 명령과 범위. 테스트0개와 통과 구분 |
| 남은 상태 | 미구현·구현했으나 미검증·확인 완료·보완 제안을 구분 |

줄번호는 수정 때 바뀔 수 있으므로 실제 경로와 식별 가능한 함수·항목을 먼저 적는다. 표·JSON·화면·문서의 값이 같은 결과를 가리키는지 본다. 기능이 바뀌면 관련 설명과 검사만 갱신한다.

## 필요한 깊이로 쉽게 설명한다

전체 구조는 주요 책임 간 관계, 기능 설명은 **입력 → 검사 → 계산/판단 → 저장 → 응답/표시**로 풀어준다. 백엔드가 없는 프로그램에 가상의 API를 붙이지 않는다. 문서·교육 과제라면 자료 선택→내용 구성→학습 확인처럼 실제 처리 흐름을 설명한다.

예외는 “처리함”으로 끝내지 말고 무엇을 거부·유지·보류·표시하는지 설명한다. 재계산, 동시 수정, 저장 실패, 오래된 데이터, 잘못된 입력, 조건 충족 실패 중 실제 관련 사례만 확인한다. 예: 역할별 탭만 만들었다면 서버 권한 검증을 구현했다고 쓰지 않는다. 메모리 저장은 재시작 후 보존과 다르다. 근사 방법은 최적해 보장과 다르다.

보고는 기능 단위로 짧게 하며 어려운 핵심 개념에는 한 사례를 붙인다. 코드의 모든 줄, 매 로그, 모든 함수의 상세 보고를 강제하지 않는다. B의 기술 설명은 A가 실제 구현과 대조한 뒤 공식 문서에 반영한다.

## 이해했는지 확인하는 방법

문서가 정확한 것과 사용자가 이해한 것은 별개다. 사용자가 연습을 요청한 경우, 허용된 단계에서 핵심 기능 하나를 자료 없이 설명해 보게 하고 실제 구현과 다른 부분만 보완한다. 설명을 출력했거나 사용자가 “다음으로”라고 했다는 이유로 이해 완료를 기록하지 않는다.

질문 예시는 해당 작업의 목적·흐름·선택·예외·검증을 확인하는 사전 학습용이다. 실제 후속 문항을 미리 알고 있다고 주장하거나 정형 모범답안을 만들지 않는다. 독립적인 구현은 이해 연습 때문에 모두 멈추지 않는다.

## 마지막 한 번 맞춘다

현재 결과·코드·양식 문장이 일치하는지 대조한다. “최적·실시간·안전·완벽·전부 검증”은 그 범위를 실제로 증명했을 때만 쓴다. 결과가 덜 완성됐더라도 사실을 숨기거나 평가용 거절·오류·사용자 기여를 연출하지 않는다.

양식 자체를 실제 형식으로 열고 필수 항목·저장 상태를 확인한다. 별도 표준 문서를 새로 만들어 오래된 공식 문서를 방치하지 않는다. 기술적 사실 확인 → 이해·가독성 정리 → 영향받은 검사 → 종료 순서다.

## 평가 단계 경계

작업 제출 확정 후 질문 생성 대기를 추가 AI 학습 시간으로 사용하지 않는다. **AI 금지 단계에서는 설명·답안·개요·첨삭·재질문 지원을 모두 중단**한다. 참고 메모 열람이 허용된다고 전제하지 않는다. 실제 질문을 외부로 보내거나 답안을 이 저장소에 기록하지 않는다. 모든 판단은 현재 공식 규칙이 우선이다.
