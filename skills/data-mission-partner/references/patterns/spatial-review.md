# 공간 검토

## 뜻과 적용

후보 위치가 목적에 맞는지 비교하는 일이다. 설치안 검토와 실제 센서·영상 분석은 다른 작업이다. 지도나 도면이 없는 자료로 정확한 가시성·면적·사각지대를 계산했다고 말하지 않는다.

## 먼저 확인

검토 목적·대상 구역, 도면/좌표/단위, 후보 위치, 장애물·높이·시야·접근 제한 등 실제 자료 범위를 본다. 면적 커버와 중요한 구역 커버, 관측 가능과 운영상 적절함을 구분한다. 예산·운영·개인정보·설치 금지 구역은 주어진 기준과 권한으로 판단한다. 규제 준수·안전 보장을 임의로 선언하지 않는다.

## 작은 첫 결과와 구조

후보·조건 읽기 → 적합/부적합/판단 보류 → 비교 근거 → 검토안 저장으로 시작한다. 기하 계산을 하는 경우 사용한 단위·좌표계·범위/차폐 가정을 명시한다. 자료가 부족하면 정밀도를 꾸미지 말고 후보 비교와 부족한 정보부터 제시한다.

시각화가 필요하면 도면과 선택 후보 상세를 연결한다. 모든 구역과 통계를 한 화면에 넣지 않는다. 모델 추천은 실무자의 승인이나 실제 설치 실행으로 취급하지 않는다.

## 검증할 위험

좌표 단위 혼합, 영역 밖 후보, 장애물 무시, 겹친 면적을 두 번 더함, 금지 구역 포함, 비용 초과, 기존 설치물과 중복을 실제 자료 범위에서 검사한다. 별도 작은 도형으로 면적·포함 계산을 검산한다. 변경 후 추천 사유와 화면이 함께 바뀌는지 확인한다.

## 실무자 질문과 설명

“무엇을 관측해야 하고, 설치하지 말아야 할 곳은 어디인가?”를 후보 하나와 연결해 묻는다. 민감한 제한이 불명확하면 승인 전 확정하지 않고 검토 대상과 필요한 확인을 남긴다.
설명은 **자료가 허용하는 계산 범위 → 평가한 조건 → 후보 선택 이유 → 기하·업무상 한계**다. 영상 AI·생체식별·외부 지도 업로드를 불필요하게 추가하지 않는다.
