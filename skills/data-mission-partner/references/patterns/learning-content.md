# 설명과 교육

## 뜻과 적용

좋은 학습 자료는 참고자료를 많이 정리한 문서가 아니라, 학습자가 기본 뜻을 이해하고 새 사례에 적용할 수 있게 돕는 결과다. 요약·교육·퀴즈·교육용 서비스 중 실제 요청을 구분한다.

## 먼저 확인

대상자의 사전 지식, 학습 목표, 사용 시간·형식, 제공 자료의 범위와 출처를 확인한다. 자료 정리를 요청받으면 원문의 용어·순서·관점을 보존하고 빠진 내용을 몰래 일반 지식으로 보충하지 않는다. 보충을 요청받은 경우 자료에 있는 내용·검증한 외부 정보·설명용 비유를 구분한다.

## 작은 첫 결과와 구조

하나의 학습 목표 → 필요한 기초 뜻 → 실제 또는 명시된 가상 사례 → 왜 그런지 → 새로운 사례 적용으로 한 단원을 먼저 완성한다. 전문가 목차부터 나열하거나 모르는 말로 모르는 말을 설명하지 않는다. 내용 난도와 질문 난도를 맞춘다. 글자 수·문서 수보다 핵심 연결과 오개념 방지를 우선한다.

서비스를 요구하면 대상/주제 선택 → 근거 있는 설명 → 필요한 상호작용 → 이해 확인의 한 흐름부터 만든다. AI 런타임 호출이 필요하다고 정해졌다면 허용된 인터페이스를 확인한다. 없으면 외부 키를 쓰거나 고정 응답을 실제 생성 AI로 표시하지 않고, 가능한 대안과 한계를 설명한다.

## 검증할 위험

정의가 처음 등장하기 전에 선행 개념이 있는지, 비유가 실제와 다른 경계가 표시됐는지, 근거가 설명을 뒷받침하는지 확인한다. 단순 용어 암기와 사례 적용을 구분한다. 퀴즈 정답·해설은 같은 규칙에 맞는지 대조한다. 모델이 “쉬워졌다”고 말한 것을 실제 학습 효과로 보고하지 않는다. 사용자 확인이 없으면 이해 향상은 미검증이다.

## 실무자 질문과 설명

“학습 후 어떤 행동이나 판단을 할 수 있어야 하나?”, “이미 아는 것과 가장 어려운 개념은 무엇인가?”를 묻는다. 답이 없으면 대상 수준의 가정을 분명히 하고 기초를 건너뛰지 않는다.
설명은 **누구를 위한 어떤 목표 → 이 순서를 택한 이유 → 자료·예시의 근거 → 이해 확인 방법 → 검증 한계**다. 긴 전문 설명과 얇은 요약 사이에서 실제 학습 목표에 필요한 연결을 남긴다.
