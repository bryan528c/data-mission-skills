# 비교 분석

## 뜻과 적용

서로 비교할 수 있는 수치를 같은 기준으로 놓고, 차이의 의미와 근거를 설명하는 작업이다. 숫자가 많다고 비교가 정확해지는 것은 아니다. 실제 질문이 조사·보고인지, 반복 조회하는 도구 제작인지 먼저 구분한다.

## 먼저 확인

누가 무슨 결정을 하는가? 비교 대상과 기간은 무엇인가? 금액·물량·비율의 단위와 분모는 같은가? 연결·별도, 전체·사업부, 발표일·측정기간, 추정·확정·수정본을 섞지 않는다. 외부 자료가 필요한지와 실제 접근 허용을 확인한다. 최신이라는 말 대신 확인한 기준 시점과 출처를 남긴다.

## 작은 첫 결과와 구조

원자료·출처 읽기 → 기준 정리 → 지표 계산 → 비교 결과와 근거 표시 순서로 한 묶음부터 완성한다. 변환한 데이터에는 원래 값·단위·출처를 찾을 수 있게 한다. 환산 기준이 없으면 임의 환율을 만들지 말고 분리하거나 확인 필요로 둔다. 생성형 설명은 검산한 값에서만 작성한다.

화면이 필요하면 비교표·기간 필터·근거 상세부터 고려한다. 사용자가 필요하지 않은 실시간 수집·예측·대시보드 전체를 만들지 않는다.

## 검증할 위험

전기값이 0·음수일 때 성장률 의미, 가중 비율과 단순 평균, 같은 기업의 서로 다른 구간, 누락값을 0으로 바꾼 오류, 반올림 전후 차이를 확인한다. 표본 몇 건의 손계산과 전체 합계를 별도로 대조한다. 같은 시점에 움직였다는 이유만으로 원인이라고 쓰지 않는다. 데이터가 없는 집단까지 대표한다고 말하지 않는다.

## 실무자 질문과 설명

“이 비교가 필요한 의사결정과 가장 중요한 지표는 무엇인가?”를 자료의 실제 불일치와 함께 묻는다. 답이 모호하면 비교 가능한 표와 미확인 항목부터 제공한다.
설명할 내용은 **왜 이 비교 기준인가 → 어디에서 통일·계산했나 → 어떤 원자료로 확인했나 → 어떤 비교는 불가능한가**다. 실적·시장 수치나 투자 결론을 지어내지 않는다.
