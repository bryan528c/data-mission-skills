# 업무에 맞는 지침만 선택하기

현재 지시서·실제 자료·요청한 결과물로 선택한다. 아래는 일반 업무를 위한 준비 지침이지, 특정 시험의 문제 목록이나 정답이 아니다. 파일명·담당자 이름·기술 유행만 보고 과제를 추정하지 않는다.

## 먼저 두 가지를 정한다

**업무가 무엇인가?** 아래에서 맞는 주지침 하나를 읽는다. 서로 다른 업무가 실제로 함께 요구될 때만 추가 지침의 필요한 절을 읽는다. 맞는 분야가 없으면 기존 핵심 지침으로 진행한다. 모든 지침을 미리 읽거나 사용자에게 여덟 개를 고르게 하지 않는다.

**무엇을 제출하는가?** 보고서/의사결정표/계산 파일/작동 프로그램/교육 자료 중 실제 요구를 따른다. 분석 주제라고 보고서만 만들거나, 데이터가 있다고 무조건 웹 대시보드·예측모델을 만들지 않는다. 특정 양식·스키마·실행 방법이 있으면 그것이 우선이다.

| 실제 업무 | 읽을 지침 | 처음 확인할 핵심 |
| --- | --- | --- |
| 시장·경쟁사·실적 비교 | [시장 비교](domains/market-comparison.md) | 대상·기간·통화·지표의 비교 가능성 |
| 소재·공급사·변경안 검토 | [변경 검토](domains/supplier-change.md) | 필수 통과 조건과 선호 기준 구분 |
| 통근·노선·시간표·배정 | [교통 계획](domains/transport-planning.md) | 수요·차량·시간 제약과 실패의 의미 |
| 식단 편성·메뉴 관심 | [식단 운영](domains/meal-planning.md) | 편성 조건과 관심 데이터의 분모 |
| 카메라 설치·구역 커버리지 | [설치안 검토](domains/camera-planning.md) | 목적·설치 가능 구역·관측 근거 |
| 층간 정렬 측정·장비 품질 | [Overlay 분석](domains/overlay-quality.md) | 측정 단위·그룹·판정식·기준 버전 |
| 가치사슬·공급망 영향 분석 | [가치사슬 분석](domains/value-chain-analysis.md) | 관계의 방향·종류·시점과 추정 범위 |
| 산업 개념·교육 콘텐츠 | [산업교육](domains/industrial-education.md) | 학습자 수준·학습목표·확인 방법 |

중간에 새 업무가 드러나면 현재 동작과 결정을 유지하고 해당 지침만 보완한다. 주제를 바꿔 읽었다고 새 프로젝트를 만들지 않는다. 각 지침의 예시 조건·화면·함수명은 필수 요구가 아니다. 출처에서 확인한 일반 개념, 작성자가 제안하는 접근, 실제 과제 조건을 구분한다.

## 어느 주제든 첫 결과는 작고 끝까지

자료·규칙 확인 → 작은 입력으로 처리 → 결과 확인 → 실제 필요한 전체 범위로 확대한다. 정답처럼 보이는 화면만 만들지 않는다. 입력·기준 버전과 결과가 대응하도록 하고, 변경·재계산·저장·조회·내보내기는 요구된 범위에서 같은 결과를 사용한다.

자료가 부족하면 없는 수치를 채우지 않는다. 명확한 규칙, 담당자 설명, 사용자가 선택한 가정, AI 제안, 미확인을 구분한다. 미확인이 있어도 독립 작업은 진행하되 중요한 기준을 몰래 확정하지 않는다.

배포 지침에 실제 과제·개인 대화·시험 식별자·답안·수치를 추가하지 않는다. 일반 자료의 공개성과 평가 자료의 반출 허가는 서로 다르다.
