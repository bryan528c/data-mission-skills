# 카메라 설치안과 구역 검토

일반 업무 지침이다. 설치안 평가를 영상 감시 AI·얼굴 식별 서비스 제작으로 바꾸지 않는다.

## 먼저 이해할 말

**시야**는 카메라가 볼 수 있는 방향과 범위이고, **커버리지**는 목적에 맞게 확인 가능한 구역의 범위다. 범위 그림이 겹쳐 보인다는 사실만으로 사람·물체를 정확히 판별할 수 있다는 뜻은 아니다.

## 확인할 질문과 자료

무엇을 관측할지, 중요한 구역, 기존 장비와 설치 가능/금지 위치, 도면·좌표·장애물·조도 자료, 예산·전원·통신 조건이 있는지 확인한다. 필요한 상세 수준과 개인정보·접근 관련 요구는 제공 규칙과 담당자 확인을 따른다. 영상이 없는데 실시간 탐지 모델을 만들지 않는다.

## 작은 첫 결과와 분업

후보 하나의 **위치·비용·대상 구역·가정·관측 근거 → 비교 결과**를 먼저 만든다. 여러 후보 비교·도면 표시가 요구되면 확장한다. A는 후보 적합성·커버리지/비용 계산·근거, B는 선택·비교·도면/표·상세 표시를 맡는다. 도면이 없으면 표로 시작하며 정밀 시야를 꾸미지 않는다.

## 놓치기 쉬운 검사

- 겹치는 구역 면적·대상 수를 두 번 더하지 않는다. 서로 다른 대상 집합의 합집합과 단순 합계를 구분한다.
- 실제 장애물·방향·거리·해상도가 계산에 반영됐는지 표시한다. 반영하지 못했다면 예상 범위이지 확인된 사각지대 제거가 아니다.
- 금지 위치나 필수 구역을 비용 점수로 무시하지 않는다. 충족하지 못한 구역을 따로 보여준다.
- 운영 목적별 기준·단위·버전을 확인한다. 외부 문서의 픽셀 수 같은 숫자를 기본 규정으로 심지 않는다.
- 설치·유지·네트워크 비용은 실제 자료에 있는 항목만 포함한다. 미확인 비용을0으로 처리하지 않는다.
- 화면상 역할 구분과 접근 통제를 구분하고, 불필요한 개인정보·실제 영상 수집은 추가하지 않는다.

## 한 사례로 설명

가상 후보A가 구역{1,2,3}, 후보B가{3,4}를 본다면 합쳐서4개 구역이지5개가 아니다. 구역4 앞 장애물이 고려되지 않았다면 “4개 관측 확인”도 아직 말할 수 없다.

## 설명 준비

설치안의 계산 가정, 누락된 현장 조건, 후보 선택 이유와 필수 미충족 구역을 실제 자료와 코드로 설명한다. 추천안을 실제 현장 안전 보장으로 표현하지 않는다.

공개 배경: [Axis 시야 상세도와 단순 모델의 한계](https://whitepapers.axis.com/en-us/pixel-density-based-on-iec-62676-4-2025). 여기의 숫자나 표준을 과제의 필수 기준으로 강제하지 않는다.

## 심화 실무: 데이터 모델·구현·검증

**입력·상태 설계:** 관측 목적·중요/금지 구역, 도면/좌표계·단위, 후보 설치 위치·방향·높이, 장애물, 기존 설치, 실제 제공된 장비 사양과 비용, 후보별 확인/추정 커버를 구분한다. 도면이 없으면 집합형 구역 비교까지만 하며 정확한 면적을 꾸미지 않는다.

**작동하는 첫 결과:** 후보/구역 조건 읽기 → 설치 가능성·필수 구역 충족 확인 → 실제 근거가 있는 범위 계산 또는 집합 비교 → 중복 제외 → 비용과 미충족 사유 → 후보별 검토 결과. A는 좌표·검사·근거, B는 표/도면/상세를 맡는다. 영상 AI를 요구하지 않았다면 만들지 않는다.

**계산·판단 규칙:** 후보 A가 보는 구역과 B가 보는 구역을 단순 합산하면 중복 계산이다. 시야각 그림이 실제 식별·안전 성능을 보장하는 것은 아니다. 장애물·조도·거리·해상도 등의 근거가 없으면 현장 확인 필요로 남긴다. 필수 금지구역이나 제약을 비용 점수로 상쇄하지 않는다.

**검증 시나리오:** 서로 겹치는 후보 구역, 금지 설치 위치, 도면 밖 좌표, cm와 m 혼합, 장애물 미반영, 비용 미확인, 중요한 구역 누락, 후보 변경 후 표·도면·내보내기의 불일치.

**설명용 가상 사례:** 가상 후보 A={1,2,3}, B={3,4}라면 합집합은 4개 구역이다. 그러나 4번 구역의 장애물 정보가 없다면 현장에서 네 구역을 실제 관측했다고 표현하지 않는다.

**실무자 상호작용과 서술형 대비:** 설치안 검토와 실제 영상 분석 구분, 커버/좌표 가정, 중복 처리 함수, 후보 제외 사유, 미확인 현장조건과 개인정보·운영 경계를 설명한다.

### 단계별로 실제 작업을 끊어 진행하기

① 감시·관측 목적과 우선 구역을 정한다. ② 기존 장치와 새 후보, 설치 금지·가능 위치를 정리한다. ③ 도면·좌표가 있으면 사용한 계산 가정을 명시한다. ④ 후보의 커버와 중복을 계산하거나 제공 자료로 비교한다. ⑤ 선택/제외 후보별 이유·현장 확인 항목을 표시한다.

### 구현 상태·데이터 연결 계약

구역·후보·장비 사양·도면 버전·관측 근거를 서로 참조 가능하게 둔다. 좌표가 없다면 설치 후보 비교를 우선하고 실제 촬영 범위나 사각지대 해소를 확정하지 않는다.

### 합격 판정 대신 실제로 확인할 것

구역 합집합, 금지 영역 포함, 방향/축척/단위 오류, 장애물 미반영, 기존 카메라 중복, 예산 자료 누락과 상세 화면의 근거를 점검한다.

### 업무 담당자에게 제안할 질문 방향

설치 목적이 위험 구역 확인인지 출입기록인지에 따라 선정 기준이 달라진다면 목적과 우선 구역부터 명확히 묻는다.
