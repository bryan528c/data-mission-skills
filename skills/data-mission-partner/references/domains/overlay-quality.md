# Overlay 품질과 장비 분석

일반 업무 지침이다. 공정의 실제 허용값·제어 조치는 제공 자료와 승인된 기준을 따른다.

## 먼저 이해할 말

**Overlay**는 반도체의 서로 다른 패턴 층이 얼마나 맞춰졌는지를 보는 개념이다. X·Y는 방향별 오차일 수 있고, 로트·웨이퍼·측정점은 서로 다른 집계 단위다. **규격 한계**와 데이터에서 계산한 **관리 한계**는 같은 기준이 아니다.

## 확인할 질문과 자료

측정 단위·부호, 오차 정의, 공정·레이어·장비·시점·표본 단위, 기준의 버전·적용 기간을 확인한다. 축별 판정인지 벡터 크기인지, 평균·최대·분포 중 무엇을 보는지 원문으로 정한다. 이상 표시와 실제 장비 조정 권한도 구분한다.

## 작은 첫 결과와 분업

측정 한 그룹을 **원값 → 적용 기준 → 판정 → 근거 상세**로 연결하고 전체 장비·기간으로 확장한다. A는 단위·판정·추이·검산, B는 요약·이상 목록·장비/측정점 상세를 담당한다. AI 설명이 필요해도 계산된 근거를 설명하는 역할부터 정하며 별도 외부 모델을 기본 설치하지 않는다.

## 놓치기 쉬운 검사

- nm와µm 등 단위를 일치시킨다. 부호가 있는 평균은 큰 양·음 오차를 상쇄할 수 있으므로 실제 기준이 요구한 통계를 계산한다.
- 축별 한계와 sqrt(X²+Y²) 한계는 다르다. 판단식을 마음대로 바꾸지 않는다.
- 서로 다른 레이어·장비·측정 조건을 섞은 평균으로 이상을 숨기지 않는다.
- 경계값의 포함 여부·누락 측정·중복·유효 표본 수·시간 범위를 확인한다.
- 특정 장비와 이상이 함께 나타났다는 사실은 원인 확정이 아니다. 관련성·원인 가설·확인에 필요한 자료를 구분한다.
- 기준 없는 데이터에 임의 한계로 합격·불합격을 찍지 않는다. 탐색적 신호는 공식 판정과 구분해 표시한다.
- 자동 레시피·장비 보정·작업 중단 명령을 실행하지 않는다. 검토용 도구와 실제 공정 제어는 별도 권한이다.

## 한 사례로 설명

가상으로 X=4, Y=4이고 축마다 절댓값5 이하가 기준이면 두 축 모두 충족한다. 하지만 벡터 크기는 약5.66이므로 벡터5 이하 기준에서는 미충족이다. 어느 쪽이 맞는지는 실제 규칙이 정한다. 평균(-6,+6)=0이더라도 큰 편차가 없다는 뜻은 아니다.

## 설명 준비

판정식·기준 선택·집계 단위가 어느 함수와 자료에 있는지, 결측과 경계값을 어떻게 검증했는지 설명한다. 측정 이상을 수율 손실의 확정 원인이나 장비 고장이라고 확대하지 않는다.

공개 배경: [ASML 측정·정렬 개념](https://www.asml.com/en/technology/lithography-principles/measuring-accuracy). 실제 제조사의 공정 허용 기준을 제공하는 자료는 아니다.

## 심화 실무: 데이터 모델·구현·검증

**입력·상태 설계:** 측정 행의 단위(점·웨이퍼·로트·장비·레이어·시간), X/Y 값·단위·재측정 상태, 규격(적용 장비·레이어·기간·버전·판정식), 결과와 이상 관찰을 나눈다. 공정 규격과 통계적 관리 한계는 같은 개념이 아니다.

**작동하는 첫 결과:** 측정 유효성·중복 검사 → 단위 통일 → 그룹/시점별 적용 규격 매칭 → 실제 기준식으로 판정 → 원자료와 판정 근거 표시 → 집계·추이. A는 매칭·판정·검증, B는 목록·필터·상세를 맡는다. 기준이 없으면 정상 대신 미판정을 표시한다.

**계산·판단 규칙:** X/Y 축별 한계와 벡터 √(X²+Y²) 한계는 다른 기준이다. +6과 -6 평균이 0이어도 큰 오차가 없는 것은 아니다. 장비·레이어별 기준을 무차별 평균하지 않는다. 이상과 고장 원인 확정, 관찰과 장비 자동 제어를 구분한다.

**검증 시나리오:** 0.006µm와 6nm의 동치, X=4·Y=4·한계5의 축별/벡터 판정 차이, 음수·경계값, 잘못된 장비 규격 매칭, 재측정 이중합산, 기준 없는 그룹, 기준 변경 뒤 화면·내보내기 일치.

**설명용 가상 사례:** 가상 X=4·Y=4는 축별 절댓값5 이하 기준이라면 통과지만, 벡터 크기5 이하는 √32≈5.66으로 미통과다. 어떤 규칙이 실제 규격인지는 원문이 정한다.

**실무자 상호작용과 서술형 대비:** 측정 단위→규격 선택→변환·판정 함수→추이 집계→이상 원인 가설·확정 구분→검증·운영 권한 경계를 설명한다.

### 단계별로 실제 작업을 끊어 진행하기

① 측정 행과 그룹 키·단위를 확인한다. ② 적절한 규격 버전·장비·레이어를 연결한다. ③ 요구한 판정식을 계산해 미판정/통과/미통과를 분리한다. ④ 기간·장비별 이상과 변화 추이를 보여준다. ⑤ 현업 조치의 권한·근거가 없는 부분은 제안·추가 확인으로 제한한다.

### 구현 상태·데이터 연결 계약

동일 측정 ID를 재측정할 경우 원본과 채택 상태를 관리한다. 어떤 규격 ID가 어떤 값에 사용됐는지 재현 가능해야 한다. 화면 숫자·설명·내보내기를 한 계산 결과에 연결한다.

### 합격 판정 대신 실제로 확인할 것

nm↔µm 변환, X/Y 절댓값과 벡터 규칙, 경계값 포함 여부, 부호 상쇄, 측정 누락과 중복, 규격의 그룹/기간 오매칭, 최신화 뒤 구버전 결과를 검증한다.

### 업무 담당자에게 제안할 질문 방향

공식 불량 판정과 운영자가 조사할 이상 신호를 동일한 색·상태로 표시할지 먼저 의도를 확인하고 서로 다른 의미를 제안한다.
