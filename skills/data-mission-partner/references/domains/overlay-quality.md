# Overlay 품질과 장비 분석

일반 업무 지침이다. 공정의 실제 허용값·제어 조치는 제공 자료와 승인된 기준을 따른다.

## 먼저 이해할 말

**Overlay**는 반도체의 서로 다른 패턴 층이 얼마나 맞춰졌는지를 보는 개념이다. X·Y는 방향별 오차일 수 있고, 로트·웨이퍼·측정점은 서로 다른 집계 단위다. **규격 한계**와 데이터에서 계산한 **관리 한계**는 같은 기준이 아니다.

## 확인할 질문과 자료

측정 단위·부호, 오차 정의, 공정·레이어·장비·시점·표본 단위, 기준의 버전·적용 기간을 확인한다. 축별 판정인지 벡터 크기인지, 평균·최대·분포 중 무엇을 보는지 원문으로 정한다. 이상 표시와 실제 장비 조정 권한도 구분한다.

## 작은 첫 결과와 분업

측정 한 그룹을 **원값 → 적용 기준 → 판정 → 근거 상세**로 연결하고 전체 장비·기간으로 확장한다. A는 단위·판정·추이·검산, B는 요약·이상 목록·장비/측정점 상세를 담당한다. AI 설명이 필요해도 계산된 근거를 설명하는 역할부터 정하며 별도 외부 모델을 기본 설치하지 않는다.

## 놓치기 쉬운 검사

- nm와µm 등 단위를 일치시킨다. 부호가 있는 평균은 큰 양·음 오차를 상쇄할 수 있으므로 실제 기준이 요구한 통계를 계산한다.
- 축별 한계와 sqrt(X²+Y²) 한계는 다르다. 판단식을 마음대로 바꾸지 않는다.
- 서로 다른 레이어·장비·측정 조건을 섞은 평균으로 이상을 숨기지 않는다.
- 경계값의 포함 여부·누락 측정·중복·유효 표본 수·시간 범위를 확인한다.
- 특정 장비와 이상이 함께 나타났다는 사실은 원인 확정이 아니다. 관련성·원인 가설·확인에 필요한 자료를 구분한다.
- 기준 없는 데이터에 임의 한계로 합격·불합격을 찍지 않는다. 탐색적 신호는 공식 판정과 구분해 표시한다.
- 자동 레시피·장비 보정·작업 중단 명령을 실행하지 않는다. 검토용 도구와 실제 공정 제어는 별도 권한이다.

## 한 사례로 설명

가상으로 X=4, Y=4이고 축마다 절댓값5 이하가 기준이면 두 축 모두 충족한다. 하지만 벡터 크기는 약5.66이므로 벡터5 이하 기준에서는 미충족이다. 어느 쪽이 맞는지는 실제 규칙이 정한다. 평균(-6,+6)=0이더라도 큰 편차가 없다는 뜻은 아니다.

## 설명 준비

판정식·기준 선택·집계 단위가 어느 함수와 자료에 있는지, 결측과 경계값을 어떻게 검증했는지 설명한다. 측정 이상을 수율 손실의 확정 원인이나 장비 고장이라고 확대하지 않는다.
