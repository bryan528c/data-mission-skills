# 시장·경쟁사 실적 비교

일반 업무 지침이다. 실제 과제의 자료·형식·목표가 우선이며 아래 기능은 선택지다.

## 먼저 이해할 말

**비교 기준**은 같은 종류의 숫자를 나란히 두는 약속이다. 분기 매출과 연간 매출, 회사 전체와 특정 사업부 매출을 그대로 순위 매기면 의미가 달라진다. **수익성 비율**은 이익을 어떤 매출로 나누는지에 따라 바뀐다.

## 확인할 질문과 자료

의사결정자가 알고 싶은 변화, 비교 기업/제품/사업 범위, 기준 기간, 통화·단위, 공시/수정 시점을 확인한다. 실제 원문이 있으면 담당자에게 다시 묻지 않는다. 기간이 서로 다르면 같은 기간으로 만들 수 있는지 확인하고, 불가능하면 비교 한계를 표시한다.

## 작은 첫 결과와 분업

한 지표에 대해 **출처 값 → 기간·단위 정리 → 비교 계산 → 근거가 보이는 결과**를 먼저 만든다. 보고서면 표와 해석, 서비스면 선택·조회·상세 출처까지 필요한 만큼 연결한다. A는 지표 정의·정규화·검산, B는 확정된 결과 구조의 필터·표시·보고 기능을 맡을 수 있다. B가 수익률 계산식을 따로 복제하지 않는다.

## 놓치기 쉬운 검사

- 중복 공시·수정본·누적 분기와 단독 분기를 구분한다. 알 수 없는 누락을0으로 채우지 않는다.
- 비율 평균은 원분모로 재계산한다. 영업이익률과 순이익률을 혼용하지 않는다.
- 환산 기준·환율 시점이 없으면 다른 통화 값을 한 합계로 만들지 않는다.
- 전기 값이0·음수일 때 성장률을 일반 양수 기준처럼 표현하지 않는다. 절대 변화와 계산 정의를 먼저 밝힌다.
- 공급 업체·고객·산업 총계를 더해 중복 매출을 산업 시장규모라고 부르지 않는다.
- 차트·표·다운로드의 기간과 값이 같고, 자료 한계와 추정이 사실에서 분리되는지 확인한다.

## 한 사례로 설명

가상 자료에서 매출100·이익10인 사업과 매출900·이익180인 사업의 합산 이익률은190/1000=19%다. 10%와20%의 단순 평균15%가 아니다. 실제 과제의 지표 정의가 같을 때만 이 계산 구조를 적용한다.

## 설명 준비

“무엇끼리 비교 가능하다고 판단했나?”, “어느 함수가 단위·기간을 처리하나?”, “출처가 바뀌면 결과를 어떻게 다시 만들나?”를 실제 파일과 계산으로 설명한다. 매매 추천이나 확인하지 않은 미래 실적을 제공하지 않는다.
