# 가치사슬·공급망 영향 분석

일반 업무 지침이다. 실제 기업 관계·시장 점유율·정량 영향은 검증된 자료가 있을 때만 사용한다.

## 먼저 이해할 말

**가치사슬**은 제품이 만들어져 사용되기까지 어떤 활동과 기업이 연결되는지를 보는 틀이다. **관계의 방향**은 누가 누구에게 무엇을 제공하는지 뜻한다. 그림의 연결선만으로 거래 규모나 손실이 확인되는 것은 아니다.

## 확인할 질문과 자료

분석할 제품·시장·사건, 필요한 단계와 기업 범위, 노드/관계의 의미, 출처·시점·신뢰 수준을 확인한다. 특정 공급자 의존인지 산업 전체의 관계인지 구분한다. 시장 비교 수치가 필요할 때만 시장 비교 지침을 함께 읽는다.

## 작은 첫 결과와 분업

근거가 있는 소수 연결로 **관계 확인 → 사건의 직접 영향 → 확인이 필요한 간접 영향**을 먼저 만든다. 결과는 표·경로 목록·관계도 중 실제 사용자 목적에 맞춘다. A는 관계 정규화·근거·영향의 가정, B는 조회·필터·근거 상세·선택한 시각화를 맡는다. 그래프 DB나 복잡한 애니메이션은 필수가 아니다.

## 놓치기 쉬운 검사

- 같은 회사의 별칭·자회사·사업부를 혼동하지 않는다. 한 회사가 여러 역할을 할 수 있다는 가능성을 자료와 대조한다.
- 공급→수요와 고객→공급 방향을 섞지 않는다. 단순한 경쟁 관계를 공급 관계로 바꾸지 않는다.
- 과거 관계와 현재 관계를 구분한다. 자료에 없는 연결·비중·대체 가능성을 그럴듯하게 생성하지 않는다.
- 여러 경로로 같은 대상을 찾았을 때 중복 합산하지 않는다. 순환 관계의 반복 탐색에는 중단 기준이 필요하다.
- “연결된 대상”은 “같은 비율로 영향을 받는 대상”이 아니다. 정량 전파는 제공된 정의·계수·가정이 있을 때만 한다.
- 산업 단계별 매출을 단순 합한 값을 중복 없는 시장규모로 표현하지 않는다. 사실·가능한 영향·의사결정 제안을 분리한다.

## 한 사례로 설명

가상으로 A가 B에 부품을 공급하고 B가 C에 제품을 공급한다고 하자. A의 공급 중단이 C의 매출을 같은 비율로 낮춘다는 결론은 재고·대체 공급·사용 비중 없이 구할 수 없다. 확인된 연결과 검토할 영향 경로까지만 표시한다.

## 설명 준비

노드와 관계가 실제로 어떤 단위인지, 출처 없는 관계는 어떻게 처리했는지, 경로와 정량 영향의 차이를 어떻게 구현했는지 설명한다.

공개 배경: [SIA 반도체 생산 과정](https://www.semiconductors.org/semiconductors-101/how-are-semiconductors-made/), [TSMC 공급망 개요](https://www.tsmc.com/english/aboutTSMC/dc_infographics_supplychain). 개별 기업의 최신 거래 사실은 이 일반 개요만으로 확정하지 않는다.

## 심화 실무: 데이터 모델·구현·검증

**입력·상태 설계:** 노드(기업/제품/공정/역할의 ID·범위), 간선(출발·도착·관계 종류·시점·근거·확인 상태), 사건·시나리오(가정·기준시점), 영향 경로(직접·간접·미확인)를 나눈다. 이름이 같은 회사와 사업부를 무조건 합치지 않는다.

**작동하는 첫 결과:** 근거가 있는 관계 2~3개 선정 → 방향·종류·기간 검증 → 사건에 연결된 직접 영향 후보 → 중복/순환 처리한 간접 경로 → 근거와 불확실성 표시. A는 관계 모델·경로 검증, B는 근거가 드러나는 목록·그래프·필터를 맡을 수 있다. 그래프 DB는 필수가 아니다.

**계산·판단 규칙:** A→B 공급은 B→A 공급을 의미하지 않는다. 여러 경로로 같은 대상을 만날 때 중복으로 집계하지 않는다. 공급 연결만으로 비중·손실률·인과를 확정하지 않는다. 숫자를 계산하려면 제공된 거래 비중·재고·대체 가능성·공식 가정이 필요하다.

**검증 시나리오:** 뒤집힌 관계 방향, 존재하지 않는 노드, 다른 이름의 동일 조직, 다른 조직의 동일 이름, 관계 유효기간, A→B→C→A 순환, 경로 중복, 시나리오 변경 뒤 옛 설명 잔존.

**설명용 가상 사례:** 가상 A가 B에 부품을 공급하고 B가 C에 제품을 공급하더라도, A의 공급 중단이 C의 매출을 몇 퍼센트 낮출지는 그 연결선만으로 계산할 수 없다.

**실무자 상호작용과 서술형 대비:** 노드·관계·시점·출처 저장 → 경로 탐색과 순환 방지 → 사실/가정/가능성 표시 → 정량 판단의 한계를 실제 함수·자료와 연결한다.
