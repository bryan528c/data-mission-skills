# Data Mission Skills

데이터 기반 대회·해커톤에서 **선택 이유를 이해하고, 실제 근거를 확인하며, 제한 시간 안에 결과를 완성하기 위한 한국어 Codex 스킬**입니다.

현재 한 개의 스킬을 제공합니다: [`data-mission-partner`](skills/data-mission-partner/SKILL.md) — 데이터 미션 파트너.

## 어떤 작업에 도움이 되나요?

| 자주 생기는 문제 | 스킬이 유도하는 작업 방식 |
| --- | --- |
| 방향은 제시하지만 실제 결과가 늦게 나옴 | 먼저 입력부터 결과 확인까지 이어지는 작은 결과를 완성 |
| 왜 그 방법을 썼는지 이해하기 어려움 | 중요한 선택의 이유와 감수한 점을 짧게 설명 |
| 숫자는 나왔지만 믿을 근거가 부족함 | 대상·기간·분모·결합 관계를 확인하고 핵심 수치를 교차 검증 |
| 수정하면서 앞서 고친 내용이 사라짐 | 고칠 부분과 유지할 부분을 구분하고 현재 버전에서 개선 |
| 도구 탐색이나 최종 수정이 끝나지 않음 | 도구의 효과와 준비 시간을 비교하고 필수 요구 충족 시 마무리 |
| 파일·화면·성과가 실제로 확인되지 않음 | 실제 실행과 원본에 근거하고 미확인 사항을 명시 |

분석, 분석에 필요한 구현, 결과 해석, 제출 준비를 하나의 흐름으로 다룹니다. 웹앱·예측 모델·특정 모델이나 MCP를 필수로 요구하지 않습니다. 실행 스크립트와 별도 패키지 의존성은 없습니다.

## 가장 간단한 사용: 파일을 직접 읽히기

사용 환경에서 공개 GitHub 자료를 가져올 수 있다면 다음을 AI에게 요청합니다.

```text
https://github.com/bryan528c/data-mission-skills 공개 저장소를 허용된 작업 공간에 가져와.
skills/data-mission-partner/SKILL.md를 읽고 이번 데이터 과제에 적용해.
참조 문서는 관련 단계에서만 읽어.
문제와 자료를 먼저 확인하고, 선택 이유를 짧게 설명하면서 실제 결과까지 진행해 줘.
```

이 방식은 문서를 명시적으로 읽혀 작업 지침으로 적용하는 방법입니다. 네이티브 스킬 설치·자동 인식과는 구분됩니다. 현재 환경의 허용 범위와 실제 문제 지시를 우선합니다.

## Codex에서 스킬로 설치하기

일반 Codex의 프로젝트 스킬 경로는 `.agents/skills`입니다. 다운로드한 `skills/data-mission-partner` 폴더 전체를 작업 프로젝트의 `.agents/skills/data-mission-partner`에 둡니다. 폴더 안의 참조 문서도 함께 유지합니다.

```text
<작업 프로젝트>/
└── .agents/skills/data-mission-partner/
    ├── SKILL.md
    ├── agents/openai.yaml
    └── references/
        ├── data-checks.md
        └── delivery-checks.md
```

스킬이 인식되면 Codex CLI에서 `/skills` 또는 `$`로 선택하거나 다음처럼 호출합니다.

```text
$data-mission-partner
문제문과 제공 자료를 읽고 요구 결과를 정리해 줘.
선택 이유를 설명하면서 가장 작은 첫 결과부터 만들고 검증해 줘.
남은 시간은 40분이야.
```

시간은 실제 상황에 맞춰 바꾸거나 생략합니다. 새 스킬이 보이지 않으면 일반 Codex에서는 재시작이 도움이 될 수 있습니다. 경로와 호출 방법은 [OpenAI 공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills)를 기준으로 합니다.

**Cofa의 실제 제공 버전에서 설치 경로, 자동 인식, `/skills` 동작은 검증하지 않았습니다.** 해당 환경이 허용하면 위의 “파일을 직접 읽히기” 방식으로 먼저 적용할 수 있습니다. 이 저장소는 Cofa 공식 도구나 대회 공식 지침이 아닙니다.

## 작업 중간과 마감에 사용하기

기존 결과를 개선할 때:

```text
$data-mission-partner
현재 결과와 최근 피드백을 먼저 읽어 줘.
이미 결정한 기준과 수정한 장점은 유지하고, 남은 오류부터 고쳐 줘.
중요한 변경은 이유와 실제 확인 결과를 함께 알려 줘.
```

마감 전에:

```text
$data-mission-partner
남은 시간은 7분이야. 문제의 필수 제출 조건과 현재 파일을 비교해 줘.
결론을 바꾸는 오류와 파일 열기부터 확인하고 제출 가능한 상태로 마무리해 줘.
실제로 검증한 것과 아직 확인하지 못한 것을 구분해 줘.
```

## 15분 연습에서 확인할 것

작은 연습용 자료 하나로 적용해 봅니다. 자료 읽기 → 첫 결과 생성 → 파일 다시 열기 → 수정 요청 → 핵심 수치 재확인까지 이어지는지 확인합니다. 아래가 안 되면 해당 실패 사례와 스킬 문구를 함께 개선합니다.

- 선택 이유를 이해할 수 있었는가?
- 설명에 그치지 않고 실제 결과가 생겼는가?
- 수정 후 유지하기로 한 내용이 남았는가?
- 검증한 범위와 미확인 부분이 구분되었는가?
- 남은 시간에 맞게 선택적 작업을 줄였는가?

스킬은 작업 지침이며 결과의 정확성이나 수상·점수를 보장하지 않습니다. 실제 모델과 대회 환경에서의 동작은 연습으로 확인해야 합니다.

## 구성

- [`SKILL.md`](skills/data-mission-partner/SKILL.md): 전체 작업 흐름과 적용 범위
- [`data-checks.md`](skills/data-mission-partner/references/data-checks.md): 수치·집계·결합·해석 확인
- [`delivery-checks.md`](skills/data-mission-partner/references/delivery-checks.md): 요구 사항·파일·최종 전달 확인
- [`openai.yaml`](skills/data-mission-partner/agents/openai.yaml): 표시 이름과 기본 호출문

공개 내용은 일반적인 작업 지침과 사용 예시입니다. 개인 대화, 대회 문제·답안, 제공 데이터, 공식 자료 원본은 배포하지 않습니다. 과제 결과물을 이 저장소에 자동으로 업로드하는 기능도 없습니다.
