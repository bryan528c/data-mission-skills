# 데이터 미션 파트너

**평소 말로 문제를 함께 정하고, 맡긴 실행은 결과와 검증까지 이어가는 한국어 스킬**입니다. 필요한 기초 뜻·실제 예·이유·확인할 곳을 연결합니다. 하나의 시작점과 이름을 유지하며 새 서비스·MCP·Hook 없이 사용합니다.

## 시작 요청 하나

```text
https://github.com/bryan528c/data-mission-skills 를 허용된 별도 위치에 가져와
START_HERE.md를 읽고 현재 과제에 적용해 줘.
실제 지시서와 지정 제출 양식부터 확인하고 필요한 지침만 골라 써.
중요한 선택은 쉽게 설명하고, 합의한 실행·검증은 이어가 줘.
```

이미 사본이 있으면 실제 경로와 버전을 확인합니다. 기존 변경·설치본을 덮어쓰지 않습니다. 기본은 **가져오기 → 읽기 → 작업**이며 설치·등록·MCP 연결은 시작 조건이 아닙니다. 준비 키트의 README와 실제 과제 지시서는 다릅니다.

| 평소 요청 | 적용할 행동 |
| --- | --- |
| “어디부터 해?” | 목표·필수 결과·양식·첫 실행과 확인 방법을 연결 |
| “이게 뭐야? 왜?” | 쉬운 뜻 → 현재 예 → 이유 → 볼 곳/다음 행동 |
| “B에게 나눠 줘” | 실제 역할·파일·공유 규칙을 정하고 충돌 없이 분업 |
| “실무자가 확답을 안 해” | 확인 사실·담당자 의견·사용자 판단·미확인을 구분 |
| “구조를 설명해야 해” | 실제 입력·핵심 처리·저장·결과·예외와 선택 근거 연결 |
| “마무리해” | 필수 결과와 지정 양식을 대조한 뒤 한 번 다듬고 종료 |

단순 질문에는 답부터 합니다. 계획만 요청하면 임의 구현하지 않고, 실행을 맡겼으면 사소한 단계마다 승인을 기다리지 않습니다. 사용자만 할 수 있는 확인은 따로 알리되 독립 작업은 계속합니다.

## 다른 업무에도 필요한 지침만

[유형 선택](skills/data-mission-partner/references/patterns/index.md)은 비교 분석, 변경 검토, 제약 배정, 일정·선호, 공간 검토, 측정 품질, 관계·영향, 설명·교육을 구분합니다. 실제 요구가 다르면 다른 유형으로 다시 분해합니다. 특정 시험의 출제 목록이나 정답 모음이 아닙니다.

[업무별 세부 안내](skills/data-mission-partner/references/scenario-router.md)는 시장 비교·공급사 변경·통근·식단·카메라·Overlay·가치사슬·산업 교육의 개념과 가상 예를 보충합니다. 해당 분야의 추가 확인이 필요할 때만 읽으며, 일반 유형 안내와 같은 검사를 반복하지 않습니다.

각 유형은 **먼저 확인할 기준 → 작은 첫 결과 → 실제 검증 → 설명할 판단**으로 구성했습니다. 모두 읽거나 모든 기능을 구현하라는 뜻이 아닙니다. 시작할 때 전체 조사 기록·테스트 자료를 읽지 않습니다.

## 여러 터미널과 제출 설명

[병렬 지침](skills/data-mission-partner/references/workflows/parallel.md)은 A 총괄, B 독립 구현, 필요시 C 읽기 전용 검토를 출발점으로 사용합니다. 독립 업무가 없으면 나누지 않습니다. 파일뿐 아니라 공통 설정·설치·DB·출력·Git 변경 담당도 정합니다. 파일 저장이 다른 세션의 읽기·적용을 보장하지 않습니다.

[지정 양식과 설계 이해](skills/data-mission-partner/references/workflows/submission-understanding.md)는 공식 양식을 보존하고 실제 코드·실무자 판단·검증을 연결합니다. 별도 인계·구조 지도는 필요한 경우에만 씁니다. 쉬운 설명을 했다는 사실과 사용자가 이해했다는 사실은 다릅니다.

## 자동 적용은 어떻게 되나요?

Skill은 일하는 지침이며, MCP는 도구와 연결하는 방식입니다. 이 시작 요청은 현재 대화가 파일을 읽고 필요한 지침을 선택하게 합니다. Clone만으로 등록되거나 백그라운드에서 자동 실행되지는 않습니다.

정식 등록을 지원하는 환경에서는 자동 선택을 허용하도록 설정했습니다. **설정·파일 복사·호스트 발견·자연어 선택·실제 준수는 각각 다른 확인 항목**입니다. Cofa 고정 버전의 실제 자동 발견·선택과 동시 실행 성능은 미검증입니다.

<details>
<summary>필요한 경우만: 프로젝트 스킬 등록</summary>

사용자가 등록을 요청하고 환경이 허용할 때만 선택 설치기를 사용합니다. 현재 Python 명령, 키트 설치기 절대 경로, 실제 과제 폴더를 확인합니다.

```text
python "/확인한/키트/scripts/install.py" --target "/실제/과제/폴더"
python "/확인한/키트/scripts/install.py" --target "/실제/과제/폴더" --apply
python "/확인한/키트/scripts/install.py" --target "/실제/과제/폴더" --check
```

첫 명령은 미리보기, 두 번째는 완전한 스킬 폴더 복사, 세 번째는 내용 일치 확인입니다. [공식 스킬 설명](https://learn.chatgpt.com/docs/build-skills)의 일반 프로젝트 경로는 `.agents/skills`이며 제공 환경 지원을 별도로 확인합니다. 같은 이름의 이전 내용과 충돌하면 보존하고 중단합니다. 두 버전의 자동 병합·우선순위를 가정하지 않습니다.

Python이 없거나 등록이 실패하면 업데이트·경로 다중 복사·관리 설정 우회 없이 완전한 START_HERE/SKILL을 직접 읽습니다. 인식된 스킬은 `$data-mission-partner`로 명시할 수 있지만 직접 읽기에는 필수가 아닙니다. 다른 세션은 필요한 지침과 역할을 별도로 확인하고, 여러 벌 설치하지 않습니다.
