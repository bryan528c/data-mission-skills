# 데이터 미션 파트너

데이터 과제를 함께 풀 때 **필요한 개념을 쉽게 설명하고, 실행·확인·수정을 이어 가도록 돕는 한국어 스킬**입니다.

**Skill은 AI의 작업 지침**, **MCP는 도구·자료와 연결하는 방식**입니다. 이 스킬은 먼저 현재 환경의 기능으로 시작하며, 새로운 연결은 실제로 도움이 될 때 검토합니다.

## 한 번 시작하고, 평소처럼 말하세요

Codex에 아래를 한 번 요청하세요. 긴 명령이나 여러 스킬 이름을 외울 필요가 없습니다.

```text
https://github.com/bryan528c/data-mission-skills 를 허용된 위치에 가져와.
START_HERE.md를 읽고 지금 과제에 적용해 줘.
필요한 개념은 쉬운 예로 설명하고, 맡긴 작업은 실제 결과와 검증까지 이어 가 줘.
```

이미 받았다면 실제 경로의 START_HERE.md를 읽어 달라고 하면 됩니다. **가져오기 → START_HERE 읽기 → 현재 과제 진행**이 기본입니다. 설치·등록·MCP 설정은 시작 조건이 아닙니다. 키트 폴더와 실제 과제 폴더·지시서는 구분합니다.

| 이렇게 말하면 | AI가 할 일 |
| --- | --- |
| “어디부터 해?” | 실제 문제·자료·현재 결과를 읽고 첫 작업과 확인 방법을 제시 |
| “분모가 뭐야? 왜 이 방법이야?” | 뜻 → 현재 자료의 예 → 필요한 이유 → 다음 행동으로 설명 |
| “결과가 이상해” | 원본·규칙·실행 결과를 비교하고 원인을 고친 뒤 다시 확인 |
| “어디를 보면 돼?” | 실제 파일/화면 위치, 할 행동, 예상 결과 안내 |
| “좋아, 다음으로” | 현재 결과를 이어받아 남은 작업 진행 |
| “마무리하고 깔끔하게 다듬어” | 필수 요구·수치·이해하기 쉬운 표현·파일 열기를 함께 확인 |

설명만 요청하면 설명만 하고, 실행을 맡기면 일반 수정과 검증을 계속합니다. 결과를 열어보라는 안내 때문에 매번 확인 답변을 기다리지 않으며, 중요한 기준 변경은 논의합니다.

예를 들어 “두 표를 연결한다”는 같은 주문 번호끼리 정보를 붙인다는 뜻입니다. **1만 원 주문이 두 번 배송되어도 매출은 1만 원**이어야 합니다. 이런 설명용 예와 실제 자료의 확인 위치를 연결해, 왜 집계 기준을 정하는지 이해하도록 돕습니다.

## 자동 적용은 어떻게 되나요?

- **위 시작 요청:** 현재 대화에서 지침을 읽고 상황별 참조 문서를 골라 적용합니다. 저장소를 받는 것만으로 자동 실행되지는 않습니다.
- **프로젝트 스킬 등록:** 호스트가 스킬을 발견하면 평소 요청에 따라 자동 선택할 수 있습니다. 이 패키지는 자동 선택을 허용하는 설정을 명시했습니다.
- **실제 확인:** 파일 복사·일치, 호스트의 발견, 자연어 요청에서 선택, 실제 지침 적용은 각각 확인합니다. 자동 선택을 허용해도 항상 선택된다는 보장은 없으며 Cofa의 실제 동작은 아직 미검증입니다.

등록하고 싶다면 Codex에 “이 프로젝트에 데이터 미션 파트너를 스킬로 등록하고, 인식되는지 확인해 줘”라고 요청하세요. 설치기는 본문·참조·출처를 함께 복사합니다.

`scripts/install.py`는 **이 키트의 루트 폴더 기준** 상대 경로입니다. 설치기와 실제 과제 폴더의 절대 경로를 확인해 사용하면 작업 폴더를 옮길 필요가 없습니다. 과제 폴더를 설치 원본 스킬 폴더 안에 지정하지 않습니다. 일반 Codex의 프로젝트 경로는 .agents/skills이며 [공식 설명](https://learn.chatgpt.com/docs/build-skills)과 대상 환경의 지원 여부를 확인합니다.

아래 경로는 예시입니다. 현재 환경에서 사용 가능한 Python 명령과 실제 경로를 먼저 확인하고, 그 셸에 맞춰 실행합니다. Python이 없으면 설치를 생략하며 제공 환경을 업데이트하지 않습니다.

```sh
python "/확인한/키트/scripts/install.py" --target "/실제/과제/폴더"
python "/확인한/키트/scripts/install.py" --target "/실제/과제/폴더" --apply
python "/확인한/키트/scripts/install.py" --target "/실제/과제/폴더" --check
```

첫 명령은 미리 보기, 두 번째는 복사, 세 번째는 파일 일치 검사입니다. 모두 원본 완전성과 경로를 먼저 검사합니다. 같은 이름의 구버전과 다르면 내용을 보존하고 차이를 확인합니다. 두 버전이 자동으로 합쳐지거나 새 버전이 우선한다고 가정하지 않습니다.

호스트에서 목록이 보이면 data-mission-partner를 확인하고 평소 문장에서 선택·적용되는지 봅니다. 직접 호출은 `$data-mission-partner`입니다. 발견되지 않으면 여러 경로에 복사하거나 전역·관리 설정 변경과 재시작을 반복하지 않습니다. 읽을 본문과 연결된 참조가 완전하면 START_HERE.md를 직접 읽혀 진행하고, 실제로 적용한 SKILL.md의 경로를 짧게 알립니다. 원본이 불완전하면 직접 읽기도 완전하다고 주장하지 않습니다.

## 무엇을 다듬었나요?

- 시작점 하나와 **필요할 때만 읽는 5개 참조 문서**로 구성했습니다.
- 짧은 보고에서도 기본 개념·실제 예·이유·볼 곳을 유지합니다.
- 이미 결정한 좋은 수정은 보존하고, 관련 확인만 다시 합니다.
- 넓게 조사한 공개 자료를 목적·이해·작업 흐름·준비 부담으로 비교했습니다.
- 별도 서비스, 특정 모델, MCP, 여러 기록 문서를 필수로 만들지 않습니다.

이 스킬은 특정 대회의 공식 도구가 아닙니다. 실제 과제 규칙과 허용 범위를 우선합니다.

같은 data-mission-partner 이름을 유지해 병행 제작된 개선을 통합했습니다. 이전의 여러 작업 스킬을 동시에 활성화할 필요는 없습니다.
