# 데이터 미션 파트너 · v2

**평소처럼 말하면 됩니다.** 문제를 함께 이해하고, 실행을 맡기고, 결과를 확인하며 다음 작업으로 이어가는 한국어 작업 지침입니다. 스킬을 여러 개 골라 쓰거나 단계마다 명령을 외울 필요가 없습니다.

## 시작은 한 번

공개 자료를 가져올 수 있는 Codex에서 다음처럼 요청하세요.

```text
https://github.com/bryan528c/data-mission-skills 를 허용된 별도 폴더에 가져와 START_HERE.md를 읽고 적용해 줘.
실제 과제와 현재 작업부터 확인하자. 중요한 선택은 이유를 짧게 설명하고,
합의한 범위의 구현·검증은 이어서 진행해. 내가 확인할 파일과 결과를 알려줘.
```

이후에는 **“그 방법으로 진행해”, “이 숫자가 왜 나왔어?”, “이 부분만 고치고 나머지는 유지해”, “10분 남았어”**처럼 말하면 됩니다. 단순 질문에는 답부터 하고, 이미 승인한 작업은 다시 계획하지 않습니다.

## 실제로 어떻게 달라지나요?

아래는 설명을 위해 만든 사례이며 실제 실행 기록이 아닙니다.

> “두 표를 연결하면 **같은 주문의 금액이 배송 건수만큼 반복될 수 있어요.** 1만원 주문이 두 번 배송됐다고 매출이 2만원은 아니죠. 배송 수량을 주문별로 먼저 합친 뒤 연결하겠습니다. 결과가 나오면 `output/summary.csv`에서 O101의 금액이 여전히 1만원인지 확인하면 됩니다.”

중요한 개념을 빼고 짧게 만드는 것이 아니라 **쉬운 뜻 → 지금 필요한 이유 → 한 사례 → 확인할 곳**을 연결합니다. 모든 단계에서 긴 설명이나 이해도 시험을 요구하지 않습니다.

## 자동으로 하는 일 / 멈춰 확인하는 일

| 상황 | 동작 |
|---|---|
| 승인된 작업의 파일 읽기·코드 수정·실행·검증 | 필요한 지침을 골라 읽고 계속 진행 |
| “왜?”, “어디서 확인해?” | 해당 개념·실제 파일·기대 결과를 바로 설명 |
| 자료 누락·중복·잘못된 계산 | 원인과 영향을 확인하고, 확정된 기준으로 수정·재검증 |
| 업무 기준이 없거나 요구가 서로 충돌 | 중요한 질문과 추천안을 짧게 제시. 독립적인 작업은 계속 |
| 새 도구가 실제 병목을 해결할 수 있음 | 효과·준비시간·허용범위를 비교. 자동으로 잔뜩 설치하지 않음 |
| 마감 전 | 필수 결과 확인 후 **내용·표현·파일 일치 여부를 한 번 다듬고 종료** |

이 저장소는 작업 방식입니다. 별도 AI 모델, 자동 채점기, 공식 대회 도구가 아닙니다. 기본 실행 의존성·MCP·설치 스크립트·Hook이 없습니다.

## 자동 적용의 정확한 범위

- 위 시작 요청은 **지침을 읽어 이번 작업에 적용**하는 방식입니다. Clone만으로 등록되거나 백그라운드에서 실행되지는 않습니다.
- 네이티브 등록을 지원하고 허용하는 Codex에서는 `skills/data-mission-partner` **폴더 전체**를 실제 프로젝트의 `.agents/skills/data-mission-partner`에 배치할 수 있습니다. 기존 같은 이름 파일은 덮어쓰지 말고 먼저 비교하세요.
- `agents/openai.yaml`은 `allow_implicit_invocation: true`입니다. 관련 작업에서 자동 선택할 수 있도록 허용하지만, **항상 선택·준수된다는 보장은 아닙니다.** 인식된 뒤 `$data-mission-partner`로 한 번 명시해 시작해도 됩니다.
- 처음 활성화한 뒤에는 본문의 상황 표에 따라 보조 문서를 선택합니다. 사용자가 보조 스킬 이름을 고르지 않습니다. 새 세션에서는 지침과 현재 상태를 다시 읽어 이어갑니다.
- 실제 Cofa 고정 버전의 등록·자동 선택은 미검증입니다. 등록이 안 되면 허용된 직접 읽기 방식으로 진행하고, Codex 업데이트나 관리 설정 변경은 하지 않습니다.

기존 Work판의 **같은 스킬·경로를 개선한 기준본**입니다. 이전 HWIJAE_COFA_SKILLS_v1의 다섯 스킬을 함께 적용할 필요가 없습니다. 기존 설치물을 자동 삭제하거나 과제 지침을 덮어쓰지는 않습니다.
