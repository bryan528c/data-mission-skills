# 데이터 미션 파트너

데이터 과제를 함께 풀 때 **필요한 개념을 쉽게 설명하고, 실행·확인·수정을 이어 가도록 돕는 한국어 스킬**입니다.

**Skill은 AI의 작업 지침**, **MCP는 도구·자료와 연결하는 방식**입니다. 이 스킬은 먼저 현재 환경의 기능으로 시작하며, 새로운 연결은 실제로 도움이 될 때 검토합니다.

## 한 번 시작하고, 평소처럼 말하세요

Codex에 아래를 한 번 요청하세요. 긴 명령이나 여러 스킬 이름을 외울 필요가 없습니다.

```text
https://github.com/bryan528c/data-mission-skills 를 허용된 위치에 가져와.
START_HERE.md를 읽고 지금 과제에 적용해 줘.
필요한 개념은 쉬운 예로 설명하고, 맡긴 작업은 실제 결과와 검증까지 이어 가 줘.
```

이미 받았다면 실제 경로의 START_HERE.md를 읽어 달라고 하면 됩니다. 가져온 키트의 README는 사용 안내이고, 실제 과제의 지시서와는 별개입니다.

| 이렇게 말하면 | AI가 할 일 |
| --- | --- |
| “어디부터 해?” | 실제 문제·자료·현재 결과를 읽고 첫 작업과 확인 방법을 제시 |
| “분모가 뭐야? 왜 이 방법이야?” | 뜻 → 현재 자료의 예 → 필요한 이유 → 다음 행동으로 설명 |
| “결과가 이상해” | 원본·규칙·실행 결과를 비교하고 원인을 고친 뒤 다시 확인 |
| “어디를 보면 돼?” | 실제 파일/화면 위치, 할 행동, 예상 결과 안내 |
| “좋아, 다음으로” | 현재 결과를 이어받아 남은 작업 진행 |
| “마무리하고 깔끔하게 다듬어” | 필수 요구·수치·이해하기 쉬운 표현·파일 열기를 함께 확인 |

설명만 요청하면 설명만 하고, 실행을 맡기면 일반 수정과 검증을 계속합니다. 결과를 열어보라는 안내 때문에 매번 확인 답변을 기다리지 않으며, 중요한 기준 변경은 논의합니다.

예를 들어 “두 표를 연결한다”는 같은 주문 번호끼리 정보를 붙인다는 뜻입니다. **1만 원 주문이 두 번 배송되어도 매출은 1만 원**이어야 합니다. 이런 설명용 예와 실제 자료의 확인 위치를 연결해, 왜 집계 기준을 정하는지 이해하도록 돕습니다.

## 자동 적용은 어떻게 되나요?

- **위 시작 요청:** 현재 대화에서 지침을 읽고 상황별 참조 문서를 골라 적용합니다. 저장소를 받는 것만으로 자동 실행되지는 않습니다.
- **프로젝트 스킬 등록:** 호스트가 스킬을 발견하면 평소 요청에 따라 자동 선택할 수 있습니다. 이 패키지는 자동 선택을 허용하는 설정을 명시했습니다.
- **실제 확인:** 설정이 켜져 있다는 사실과 호스트가 발견·선택했다는 사실은 다릅니다. Cofa 제공 버전의 자동 발견·선택은 아직 검증하지 않았습니다.

등록하고 싶다면 Codex에 “이 프로젝트에 데이터 미션 파트너를 스킬로 등록하고, 인식되는지 확인해 줘”라고 요청하세요. 설치기는 본문·참조·출처를 함께 복사합니다.

<details>
<summary>AI 또는 직접 설치할 사람이 볼 세부 방법</summary>

실제 과제 폴더를 대상으로 지정합니다. 일반 Codex의 프로젝트 경로는 .agents/skills입니다. [OpenAI 공식 설명](https://learn.chatgpt.com/docs/build-skills)을 따르며 대상 환경의 실제 지원 여부를 확인합니다.

```sh
python scripts/install.py --target /실제/과제/폴더
python scripts/install.py --target /실제/과제/폴더 --apply
python scripts/install.py --target /실제/과제/폴더 --check
```

첫 명령은 변경 예정만 보여 줍니다. 두 번째가 복사, 세 번째가 파일 일치 검사입니다. Python 명령 이름이 python3인 환경은 그 이름을 사용합니다. 기존 파일과 다르면 덮어쓰지 않습니다. 기존 AGENTS·Codex·MCP·Git 설정은 수정하지 않습니다.

호스트에서 스킬 목록이 보이면 data-mission-partner를 확인하고 평소 작업 문장으로 선택되는지 시험합니다. 직접 호출은 `$data-mission-partner`입니다. Cofa에서는 확인되지 않은 경로나 재시작·업데이트를 강제하지 말고, 자동 발견이 지원되지 않으면 START_HERE.md를 직접 읽히는 방식으로 진행합니다.

## 무엇을 다듬었나요?

- 시작점 하나와 **필요할 때만 읽는 5개 참조 문서**로 구성했습니다.
- 짧은 보고에서도 기본 개념·실제 예·이유·볼 곳을 유지합니다.
- 이미 결정한 좋은 수정은 보존하고, 관련 확인만 다시 합니다.
- 넓게 조사한 공개 자료를 목적·이해·작업 흐름·준비 부담으로 비교했습니다.
- 별도 서비스, 특정 모델, MCP, 여러 기록 문서를 필수로 만들지 않습니다.

이 스킬은 특정 대회의 공식 도구가 아닙니다. 실제 과제 규칙과 허용 범위를 우선합니다.

같은 data-mission-partner 이름을 유지해 병행 제작된 개선을 통합했습니다. 이전의 여러 작업 스킬을 동시에 활성화할 필요는 없습니다. 기존 설치 파일이 다르면 설치기가 덮어쓰지 않으므로 차이를 비교한 뒤 갱신합니다.
